# Support

This repository holds default community health files and reusable GitHub Actions
workflows for the [donny-devops](https://github.com/donny-devops) account.

## How to get help

| Need | Where to go |
| :--- | :--- |
| Bug in a specific project | Open a **Bug report** on that repository |
| Feature idea | Open a **Feature request** on that repository |
| Question about reusable workflows | Open a **Question** issue in this repository |
| Security vulnerability | Follow [`SECURITY.md`](SECURITY.md) — do not file a public issue |
| Business / consulting | [pipefishlabs.io](https://pipefishlabs.io) or [email](mailto:adonis-jimenez@outlook.com) |

## Response targets

- Issues and discussions: acknowledged within 5 business days
- Security reports: acknowledged within 48 hours (see [`SECURITY.md`](SECURITY.md))
